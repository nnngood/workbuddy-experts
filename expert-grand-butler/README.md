# 专家大掌柜（expert-grand-butler）

一个**技能调度型** WorkBuddy 专家：你派活，它派技能。它不亲手产出文档/PPT/代码，而是读懂你的需求、上下文与记忆，挑出**免费且被大家验证好用**的技能，排成一条流水线去完成，最后替你验收。

## 核心能力

- 任务六问解析，判定成果形态与质量标准，信息不足先问清、不硬猜
- 查组合库记忆 → 本地检索打分 → 按需外检免费技能 → 排「调研→生产→加工→质检」调用链
- 两条铁律：**只用免费技能**、**优先被验证好用的技能**（已晋级组合 > 试用中组合 > 首次匹配）
- 交付必过质检；成功后沉淀调用链记忆，重复 2 次自动晋级为预置组合，越用越准

## 安装 / 使用

1. 将整个 `专家大掌柜` 目录压缩为 `专家大掌柜.zip`（包内第一层即上述目录结构）。
2. 在 WorkBuddy 中把该 zip 拖入对话框，说「安装这个专家」；或按客户端「我的专家 → 创建专家」流程导入。
3. 在「我的专家」中召唤「专家大掌柜」，直接描述任务即可。

> 提示：专家名称创建后不可修改，导入前请确认名称为「专家大掌柜」。

## 依赖

- 内置技能 `skill-auto-router`（免费，零第三方依赖，任意 Python 3.9+ 可运行）。
- 不依赖任何付费技能或外部连接器；若任务确需付费/外部授权能力，专家会先告知并征得同意。

| 配置项 | 值 |
|---|---|
| expertType | agent |
| categoryId | 09-OperationsHR |
| 默认技能 | skill-auto-router（内置） |
| 版本 | 1.0.0 |
